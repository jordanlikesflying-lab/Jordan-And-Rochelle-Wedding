Jordan & Rochelle Wedding Manager v1.1.3

NO SQL REQUIRED.

Changes:
- "Delete Duplicate RSVP" is now simply "Delete RSVP".
- Delete confirmation text no longer calls the RSVP a duplicate.
- Possible RSVP duplicates now have a Review / Verify button.
- Review shows the matching RSVP(s) and why they were flagged.
- "Verify Not Duplicate" permanently dismisses that duplicate pair using the existing duplicate_dismissals system.
- The same RSVP verification action is available from Guest Profiles when applicable.
- Existing invitation duplicate review remains unchanged.
- All v1.1.2, v1.1.1, and v1.1.0 features remain included.
